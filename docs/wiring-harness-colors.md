# BMO 面板线色对照表（可转交他人接线）

线序均为**线束朝自己、从左到右**。MCU 为涂鸦 **T5AI-Core**。  
供电一律 **3.3V**（屏幕禁止 5V）。完整 GPIO 说明另见 [bmo-pins.md](./bmo-pins.md)、屏幕细节见 [st7305-wiring.md](./st7305-wiring.md)。

---

## 1. 红色大圆键（对话）

| 左→右线色 | 功能 | 接到开发板 |
|-----------|------|------------|
| 白 | GND | GND |
| 紫 | 信号 | **P12** |
| 蓝 | VCC | 3.3V |

固件：`ai_chat_button`（短按唤醒/打断，长按对讲，双击切模式）。需打 `patches/board_chat_button_p12.patch`。

---

## 2. 绿色小圆键（刷新 / 彩蛋）

| 左→右线色 | 功能 | 接到开发板 |
|-----------|------|------------|
| 黑 | GND | GND |
| 白 | 信号 | **P19** |
| 灰 | VCC | 3.3V |

---

## 3. 三角键（返回）

| 左→右线色 | 功能 | 接到开发板 |
|-----------|------|------------|
| 绿 | GND | GND |
| 黄 | 信号 | **P26** |
| 橙 | VCC | 3.3V |

游戏中：退回游戏选择页；其它页：回表情页。

---

## 4. 摇杆 + 双按键模块

| 左→右线色 | 功能 | 接到开发板 | 固件行为 |
|-----------|------|------------|----------|
| 紫 | COM | **3.3V**（与单键模块 VCC 同侧） | 公共端 |
| 蓝 | UP | **P4** | 音量 + |
| 绿 | DOWN | **P5** | 音量 − |
| 黄 | LEFT | **P7** | 上一页 |
| 橙 | RIGHT | **P8** | 下一页 |
| 红 | MID | **P22** | 刷新天气/日历；部分页进入浏览/设置 |
| 红 | SET | **P23** | 静音 / 取消静音 |
| 咖啡 | RST | **P25** | 短按系统信息；长按 5 秒重置网络 |

两根都是红色时：靠**线序位置**区分——靠 MID 那根是十字中，最靠后的红是 SET；咖啡色是 RST。  
COM 接 3.3V（本机实测按键按下为高电平）；若改接 GND，固件侧十字/绿/三角仍可自适应，但红键对话走 SDK 固定极性，不要改红键接线方式。

---

## 5. ST7305 屏幕排线

线序左→右（与屏幕丝印 1→7 一致）：

| 左→右线色 | 屏幕丝印 | 功能 | 接到开发板 |
|-----------|----------|------|------------|
| 黑 | GND | 地 | GND |
| 白 | VCC | 电源 | **3.3V** |
| 灰 | SCL | SPI 时钟 | **P14** |
| 紫 | SDA | SPI 数据 (MOSI) | **P16** |
| 蓝 | RST | 复位 | **P6** |
| 绿 | DC | 数据/命令 | **P17** |
| 黄 | CS | 片选 | **P15** |

说明：线束上若两根都标成「DC」，**绿色是 DC、黄色是 CS**（对应屏幕第 6、7 脚）。TE 本版悬空。

---

## 6. 总览（按 MCU 脚）

| GPIO | 功能 | 线色提示 |
|------|------|----------|
| P4 | 摇杆 UP | 蓝 |
| P5 | 摇杆 DOWN | 绿 |
| P6 | 屏 RST | 蓝（屏线） |
| P7 | 摇杆 LEFT | 黄 |
| P8 | 摇杆 RIGHT | 橙 |
| P12 | 红键信号 | 紫 |
| P14 | 屏 SCL | 灰 |
| P15 | 屏 CS | 黄（屏线） |
| P16 | 屏 SDA | 紫（屏线） |
| P17 | 屏 DC | 绿（屏线） |
| P19 | 绿键信号 | 白 |
| P22 | 摇杆 MID | 红（前） |
| P23 | SET 静音 | 红（后） |
| P25 | RST 系统信息 | 咖啡 |
| P26 | 三角信号 | 黄 |

舵机（若接）：左臂 **P18**，右臂 **P24**；**独立 5V≥2A 供电 + 与板子共 GND**，信号线另接，勿从板子 5V 大电流取电。

---

## 7. 接线注意

1. 先断电再插拔杜邦线。  
2. 屏、按键逻辑电平均为 **3.3V**；舵机电源 5V 与逻辑地共地。  
3. 勿占用：P13（板级 LDO）、P0/P1（日志）、P10/P11（UART0）。  
4. 装完后串口 460800 可见 `[bmo-btn] … DOWN/UP`；红键应出现 `ai_chat_button pressed`。
